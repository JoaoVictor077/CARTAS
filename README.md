# UNO — HTML, CSS e JavaScript

Esta versão roda diretamente no navegador, sem Python, Flask ou servidor backend.

## Executar no computador
1. Extraia o ZIP.
2. Abra a pasta `uno_html_css_js`.
3. Dê dois cliques em `index.html` (ou abra-o no navegador).

## Publicar gratuitamente no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie os três arquivos `index.html`, `style.css` e `game.js` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na página Pages.

## Regras desta versão
- Partida de um jogador contra o computador.
- 7 cartas para cada jogador.
- Cartas numéricas, Bloqueio, Inverter, +2, Coringa e +4.
- Escolha de cor ao jogar um Coringa.
- Compra de carta, passar a vez e aviso UNO.
- Em partida de dois jogadores, Bloqueio e Inverter fazem o adversário perder a vez.

É uma implementação demonstrativa simplificada: não inclui multiplayer online, empilhamento de +2/+4 ou desafio do +4.
